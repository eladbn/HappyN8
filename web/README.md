# HappyN8 web

React 19 single-page app built with Vite and TypeScript. It uses TanStack Query for data fetching,
React Router for navigation and React Flow (`@xyflow/react`) for the workflow canvas.

## Run

```bash
npm install
npm run dev     # http://localhost:5173, proxies /api to http://localhost:8080
npm run build   # tsc --noEmit + vite build → dist/
npm test        # vitest (src/**/*.test.ts)
```

Start the server (`npm --prefix ../server run dev`) alongside it for a working API.

## Layout

| Path | Contents |
|------|----------|
| `src/main.tsx` | App bootstrap and routes. |
| `src/api/` | HTTP client, React Query hooks and shared types. |
| `src/pages/` | Top-level pages: workflows, executions, agents, credentials, data tables, variables, activity, users, n8n connection, login. |
| `src/editor/` | Workflow editor: canvas, nodes, node picker, parameter forms, executions/history/settings views and the editor store. |
| `src/components/` | Shared layout and UI building blocks. |
| `src/lib/` | Pure helpers (formatting, workflow and execution logic, organizing) with unit tests. |
| `public/brand/` | Logos, icons and the web manifest (generated by `scripts/brand/logos.mjs` and `icons.mjs`). |
